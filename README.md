# Simple GIF Editor

Веб-сервіс для перетворення відео на GIF з обрізанням за часом,
накладанням тексту, пресетами стиснення, прогнозом розміру файла та
конвертацією під заданий розмір.

## Стек

- **Бекенд:** Python 3.12, FastAPI, FFmpeg (`palettegen` / `paletteuse`), gifsicle
- **Фронтенд:** React + Vite + TypeScript (з'явиться на етапі 5)
- **Інфраструктура:** Docker, docker-compose, GitHub Actions

## Структура

```
backend/             FastAPI-застосунок і тести (pytest)
frontend/            веб-інтерфейс (поки порожньо)
docker/              Dockerfile-и та docker-compose
.github/workflows/   CI: лінт і тести
```

## Запуск

### Docker

```bash
docker compose -f docker/docker-compose.yml up --build
```

Сервіс буде доступний на <http://localhost:8000>, інтерактивна документація
API на <http://localhost:8000/docs>.

### Локально

Потрібні Python 3.12+, FFmpeg і gifsicle у `PATH`.

```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
uvicorn app.main:app --reload
```

## API

### `POST /api/convert`

Приймає відео (`multipart/form-data`) і повертає GIF.

| Поле    | Тип  | За замовчуванням | Опис                              |
|---------|------|------------------|-----------------------------------|
| `file`  | файл | обов'язкове      | відео (mp4, mov, webm тощо)       |
| `preset` | str | немає            | пресет стиснення: `high`, `medium`, `low` |
| `fps`   | int  | `10`             | частота кадрів, 1–30              |
| `width` | int  | `480`            | ширина в пікселях, 16–1920; висота підбирається пропорційно |
| `colors` | int | `256`            | кількість кольорів у палітрі, 2–256 |
| `lossy` | int  | `0`              | рівень стиснення з втратами (gifsicle `--lossy`), 0–200; `0` вимикає |
| `target_size_kb` | int | немає    | максимальний розмір GIF у КБ, від 10 |
| `start` | float | `0`             | початок фрагмента, у секундах     |
| `end`   | float | кінець відео    | кінець фрагмента, у секундах; не разом з `duration` |
| `duration` | float | до кінця відео | тривалість фрагмента, у секундах; не разом з `end` |

Якщо задано `start`, `end` або `duration`, сервіс перевіряє їх за
тривалістю відео: `start` має бути меншим за тривалість, а кінець фрагмента
не може виходити за межі відео.

#### Стиснення

Пресет задає одразу кілька параметрів. Поля `fps`, `width`, `colors` і
`lossy`, якщо їх передати, мають пріоритет над пресетом. Без пресета діють
значення за замовчуванням з таблиці вище.

| Пресет   | `fps` | `width` | `colors` | `lossy` | Дизеринг     |
|----------|-------|---------|----------|---------|--------------|
| `high`   | 15    | 480     | 256      | 0       | Sierra       |
| `medium` | 12    | 400     | 128      | 40      | Bayer        |
| `low`    | 8     | 320     | 64       | 80      | Bayer        |

З `target_size_kb` сервіс бере ці параметри як стартові й поступово знижує
палітру, частоту кадрів, а потім ширину, доки прогнозований розмір не влізе
в ліміт. Якщо готовий файл усе одно більший, пробує наступний крок. Коли
навіть найменші параметри не вкладаються, повертає `422`.

Фактично використані параметри повертаються в заголовках `X-Gif-Fps`,
`X-Gif-Width`, `X-Gif-Colors` і `X-Gif-Lossy`.

#### Текст

Поле `text` накладає підпис на GIF. Решта полів `text_*` діють лише разом
із ним. Розміри та координати задаються в пікселях готового GIF, тобто після
зміни ширини.

| Поле                 | Тип   | За замовчуванням | Опис                                   |
|----------------------|-------|------------------|----------------------------------------|
| `text`               | str   | немає            | підпис, до 500 символів; можна кілька рядків |
| `text_size`          | int   | `32`             | розмір шрифту, 8–200                   |
| `text_color`         | str   | `white`          | колір тексту                           |
| `text_position`      | str   | `bottom`         | `top`, `center`, `bottom`, `top-left`, `top-right`, `bottom-left`, `bottom-right` |
| `text_x`, `text_y`   | int   | немає            | лівий верхній кут тексту; задаються разом і замінюють `text_position` |
| `text_outline`       | int   | `2`              | товщина обведення, 0–10; `0` вимикає   |
| `text_outline_color` | str   | `black`          | колір обведення                        |
| `text_box`           | bool  | `false`          | підкладка під текстом                  |
| `text_box_color`     | str   | `black@0.5`      | колір підкладки                        |
| `text_start`         | float | початок GIF      | коли текст з'являється, у секундах від початку GIF |
| `text_end`           | float | кінець GIF       | коли текст зникає, у секундах від початку GIF |

Колір задається назвою (`white`, `red`, `yellow`…) або як `#RRGGBB` /
`#RRGGBBAA`, з необов'язковою прозорістю через `@`, наприклад `black@0.5`.
Час тексту рахується від початку готового GIF, тобто вже після обрізання.

Текст малюється шрифтом DejaVu Sans Bold, який лежить у репозиторії
(`backend/app/fonts`, ліцензія поруч), тому кирилиця працює без системних
шрифтів. Інший шрифт можна задати змінною `FONT_FILE`.

```bash
curl -F "file=@video.mp4" -F "fps=12" -F "width=320" \
     http://localhost:8000/api/convert -o result.gif

# фрагмент з 5-ї по 8-му секунду
curl -F "file=@video.mp4" -F "start=5" -F "end=8" \
     http://localhost:8000/api/convert -o clip.gif

# пресет medium, але ширина 320
curl -F "file=@video.mp4" -F "preset=medium" -F "width=320" \
     http://localhost:8000/api/convert -o medium.gif

# GIF не більше 2 МБ
curl -F "file=@video.mp4" -F "target_size_kb=2048" \
     http://localhost:8000/api/convert -o small.gif

# підпис унизу на темній підкладці, видно з 1-ї по 3-тю секунду GIF
curl -F "file=@video.mp4" -F "text=Привіт!" -F "text_size=40" \
     -F "text_box=true" -F "text_start=1" -F "text_end=3" \
     http://localhost:8000/api/convert -o caption.gif
```

Коди помилок: `400` порожній файл, `413` файл завеликий, `422` некоректні
параметри (зокрема фрагмент поза межами відео) або файл не вдалося
конвертувати.

### `POST /api/estimate`

Приймає ті самі поля, що й `/api/convert`, і повертає прогноз розміру GIF
без самого файла:

```json
{
  "estimated_bytes": 1105437,
  "duration": 12.0,
  "exact": false,
  "settings": {"fps": 12, "width": 400, "colors": 128, "lossy": 40, "dither": "bayer"}
}
```

Фрагменти до ~4 секунд конвертуються повністю, тож розмір точний
(`"exact": true`). Для довших сервіс конвертує три короткі семпли з різних
частин фрагмента тим самим конвеєром і екстраполює розмір на всю тривалість.
З `target_size_kb` у `settings` будуть параметри, які обере `/api/convert`.

### `GET /api/presets`

Параметри кожного пресета стиснення.

### `GET /health`

Перевірка, що сервіс працює.

## Налаштування

| Змінна             | За замовчуванням | Опис                               |
|--------------------|------------------|------------------------------------|
| `MAX_UPLOAD_MB`    | `100`            | максимальний розмір відео          |
| `FFMPEG_TIMEOUT_S` | `120`            | ліміт часу на одну конвертацію     |
| `FFMPEG_BIN`       | `ffmpeg`         | шлях до FFmpeg                     |
| `FFPROBE_BIN`      | `ffprobe`        | шлях до ffprobe                    |
| `GIFSICLE_BIN`     | `gifsicle`       | шлях до gifsicle                   |
| `FONT_FILE`        | вбудований DejaVu Sans Bold | шрифт для тексту (`.ttf` / `.otf`) |
